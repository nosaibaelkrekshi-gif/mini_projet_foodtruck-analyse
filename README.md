   ## Jour 2 — Mini-rapport exploratoire
   Analyse de 407 réponses à une enquête sur les food trucks : critères de choix, moments de consommation, canaux d'acquisition et fidélisation.
   - Notebook : `Nosaiba_ELkrekshi_J2_05_TP_mini_rapport.ipynb`
   - Principaux résultats : le dîner concentre 64 % des clients, le bouche-à-oreille fidélise le plus (20,9 % de clients réguliers) et les réseaux sociaux génèrent les plus gros paniers (23,7 € en moyenne).
